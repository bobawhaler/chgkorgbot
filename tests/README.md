# Тесты и спецификация API сайта рейтинга (`api.rating.chgk.info`)

В этой папке собраны тесты для регулярной проверки работоспособности вызовов API сайта рейтинга и актуальная спецификация API.

## Содержимое папки

* **`test_rating_api.py`** — набор тестов на базе `unittest`, покрывающий все используемые ботом вызовы к API сайта рейтинга:
  * Доступность корня и спецификации Hydra/OpenAPI.
  * Получение турнира по ID (`GET /tournaments/{id}`) и валидация ключевых полей.
  * Выборка турниров по диапазону дат и типам (`GET /tournaments`).
  * Получение заявок площадки по дате старта и дате подачи (`GET /venues/{id}/requests`).
  * Получение деталей заявки синхрона (`GET /tournament_synch_requests/{id}`).
  * Работа с командами: получение по ID, поиск по названию, сезоны игроков команды, список турниров команды.
  * Работа с игроками: получение по ID, сезоны/город игрока, поиск по фамилии и имени.
  * Результаты турнира с фильтром по площадке и составами команд (`GET /tournaments/{id}/results?venue=...&includeTeamMembers=1`).
  * Проверка известных особенностей и ограничений API (игнорирование сервером фильтра `?team=` в результатах турнира, игнорирование `?patronymic` при поиске игроков).

* **`docs.jsonld`** — актуальная JSON-LD спецификация Hydra API с `https://api.rating.chgk.info/docs.jsonld`.

## Запуск тестов

Тест выполняет реальные HTTPS-запросы к живому серверу `https://api.rating.chgk.info` и предназначен **только для ручной проверки** (при автоматическом обнаружении через `unittest discover` или `pytest` тест автоматически пропускается).

### Ручной запуск:
```bash
python3 tests/test_rating_api.py
```

Или с явным указанием флага:
```bash
RUN_LIVE_API_TESTS=1 python3 -m unittest tests/test_rating_api.py
```

## Обновление спецификации API

Спецификацию можно обновить командой:
```bash
curl -H "Accept: application/ld+json" https://api.rating.chgk.info/docs.jsonld -o tests/docs.jsonld
```
