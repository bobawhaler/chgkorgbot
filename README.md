# ChGK Org Bot

[ChGKOrgBot](https://t.me/gamepollbot) — это Telegram-бот, предназначенный для помощи организаторам турниров по «Что? Где? Когда?» (ЧГК):
- Автоматический поиск турниров и создание опросов для выбора игровых дней;
- Мониторинг новых заявленных площадок;
- Управление составами команд игрового дня с автоматическим определением статусов игроков (**К** — капитан, **Б** — базовый, **Л** — легионер);
- Экспорт сформированных составов в формате CSV для загрузки на [Турнирный сайт сообщества знатоков](https://rating.chgk.info).

Бот полностью интегрирован с REST API рейтинга (`https://api.rating.chgk.info`).

---

## Основные возможности

### 1. Поиск турниров и создание опросов
* **Поиск турниров (`/tourns` и `/rtourns`):**
  * `/tourns [дата/время]`: Показывает список всех доступных синхронных и асинхронных турниров.
  * `/rtourns [дата/время]`: Аналогично `/tourns`, но с фильтрацией только по турнирам, учитываемым в рейтинге.
  * *Формат даты/времени:* текстом (`завтра в 18:00`, `в субботу`, `в пятницу 19:00`) или датой (`15.08`, `2026-08-15`, `15.08.2026`). Если параметр не указан — выводятся турниры на `сегодня`.
  * *Примеры:* `/tourns завтра в 18:00`, `/rtourns 15.08`
* **Создание опросов (`/poll`):**
  * `/poll <номера> [название] [до дата/время]`: Создаёт голосование по выбранным турнирам из последнего выданного списка (`/tourns` или `/rtourns`).
    * **`<номера>`**: Номера турниров через запятую без пробелов (напр. `1,3,5` или `1,2`).
    * **`[название]`**: Необязательный заголовок/тема опроса (по умолчанию *"Выбираем"*).
    * **`[до дата/время]`**: Необязательное время автоматического закрытия опроса с подведением итогов после ключевого слова `до` (напр. `до пятницы 20:00`, `до 20:00`, `до 15.08 18:00`).
    * *Пример:* `/poll 1,3,5 Играем в эти выходные до пятницы 20:00`
* **Управление опросами:**
  * `/stop` (reply на опрос): Завершает опрос и подводит итоги.
  * `/cancel` (reply на опрос): Завершает опрос без определения победителя.

### 2. Управление составами команд и экспорт заявки
* **Регистрация команды на турнир (в групповом чате):**
  * Для регистрации команды достаточно отправки сообщения в формате **Reply с названием вашей команды** на анонс турнира.
  * `/unregister` (или `отмена` как reply): Отмена регистрации команды на турнир.
* **Telegram Mini App (WebApp) для управления составами (`/miniapp` / `/app`):**
  * Полнофункциональное современное веб-приложение внутри Telegram для удобного ввода и редактирования составов.
  * Интуитивный выбор турниров с авто-сортировкой (новые сверху) и фильтрацией по ролям (капитан, представитель, участник).
  * Выбор и смена базовой команды с автоматическим пересчётом статусов игроков (**К** / **Б** / **Л**) в реальном времени.
  * Мгновенный выбор разового названия команды из ранее использованных или ввод нового.
  * Поиск игроков и базовых команд по сайту рейтинга с интерактивными подсказками.
* **Меню управления составом в Telegram-боте (`/roster` / `/myteams` в ЛС):**
  * Позволяет формировать состав команды на конкретную игру через интерактивное кнопочное меню в ЛС.
  * Поиск базовой команды и игроков на сайте рейтинга с расчётом актуального рейтинга и историей заигранных игроков.
  * Быстрое добавление игроков из подсказок (ранее заигранные игроки + базовый состав команды + профиль капитана).
  * Ручное добавление игроков без ID (не зарегистрированных на сайте рейтинга).
* **Автоматическое определение статусов игроков (К / Б / Л):**
  * **К** (Капитан): Назначается игроку, который указан капитаном базового состава команды на сайте рейтинга.
  * **Б** (Базовый игрок): Назначается игроку, входящему в базовый состав команды текущего сезона.
  * **Л** (Легионер): Назначается игроку вне базового состава, игроку без ID или при отсутствии привязанной базовой команды.
  * Статус любого игрока легко переключается нажатием в интерфейсе.
* **Привязка личного профиля на сайте рейтинга (`/setmyid` / `/myid`):**
  * Позволяет привязать ваш ID сайта рейтинга (по ID или ФИО) для автоматического добавления вас в подсказки при формировании состава.
* **Экспорт составов в CSV (`/rosters` / `/exportroster` / `/csv`):**
  * Генерирует и отправляет файл в формате CSV, полностью готовый для импорта состава на [Турнирном сайте сообщества знатоков](https://rating.chgk.info).

### 3. Настройки чата и администрирование
* `/setregisterteams <on|off>`: Включение или отключение регистрации команд на турнир в чате.
* `/setcollectrosters <on|off>`: Включение или отключение ввода и сбора составов команд.
* `/setvenues <ID_площадки1,ID_площадки2...>`: Настройка ID площадок с сайта рейтинга для мониторинга новых заявок.
* `/settimezone <часовой_пояс>`: Настройка часового пояса (напр. `Europe/Moscow`).
* `/setmindifficulty <N>` / `/setmaxdifficulty <N>`: Настройка фильтра сложности турниров.
* `/help`: Справка по доступным командам с автоматическим учётом активности функций.
* **Команды администратора (доступны только администратору бота):**
  * `/del` (как reply на сообщение): Удаление сообщения бота из чата и самой команды.
  * `/react` (как reply на сообщение): Установка реакции ❤️ на сообщение регистрации и удаление команды.

## Архитектура и запуск (для разработчиков)

Проект написан на Python с использованием веб-фреймворка **Flask** и разворачивается на **Google App Engine (Standard Environment)**.

* **База данных:** Google Cloud Datastore.
* **Очередь задач:** Google Cloud Tasks.
* **Фоновый поиск API:** Параллельная многостраничная выгрузка с кэшированием результатов турниров (`ThreadPoolExecutor`).
* **Файл спецификации API:** В репозитории присутствует `docs.json` (JSON-LD спецификация API рейтинга) для справочных целей. При деплое на GAE файл исключается через `.gcloudignore`.

### Переменные окружения (`env.yaml`)
Перед запуском создайте файл `env.yaml` на основе `env_template.yaml`:
* `PROJECT_ID`: ID проекта в Google Cloud.
* `TELEGRAM_API_TOKEN`: Токен Telegram-бота.
* `OBFUSCATION_TOKEN`: Токен обфускации URL вебхука.
* `CLOUD_TASKS_QUEUE`: Имя очереди Cloud Tasks (по умолчанию `bot-tasks`).
* `APP_REGION`: Регион Google Cloud (напр. `us-central1`).

### Настройка Google Cloud Tasks & Artifact Registry
```bash
# Создание очереди задач
gcloud tasks queues create bot-tasks --location=APP_REGION

# Настройка политики очистки старых образов App Engine
gcloud artifacts repositories set-cleanup-policies gae-standard \
    --location=APP_REGION \
    --project=PROJECT_ID \
    --policy=artifact_registry_policy.json \
    --no-dry-run
```

### Установка вебхука Telegram
Установить вебхук можно единоразовым запросом к эндпоинту приложения:
`https://<PROJECT_ID>.appspot.com/setwebhook`
